# TvConIdeas — Portfolio Web

Portfolio personal de **Ian Francano** (`TvConIdeas`), enfocado en desarrollo web, diseño responsivo y experiencias interactivas.

## Características principales

- **Diseño responsivo:** Adaptado a escritorio y dispositivos móviles.
- **Estética visual:** Fondo atmosférico, composición editorial y televisor retro en la sección principal.
- **Catálogo dinámico:** Carga de proyectos desde `data/demos.json` mediante `js/app.js`.
- **Acceso directo:** Enlaces a proyectos, GitHub, redes sociales y contacto vía WhatsApp.

## Estructura del proyecto

```text
tvconideas-portfolio/
├── css/
│   └── styles.css      # Estilos, animaciones y diseño responsivo
├── data/
│   └── demos.json      # Catálogo de proyectos y demos mostrados en la web
├── img/                # Recursos gráficos e imágenes del sitio
├── js/
│   └── app.js          # Renderizado dinámico de proyectos e interacciones
└── index.html          # Estructura principal del portfolio
