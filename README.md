# MyPage — Portfolio de Ian Francano (`TvConIdeas`)

Portfolio web personal de **Ian Francano** (`TvConIdeas`), enfocado en desarrollo web, aplicaciones de gestión y proyectos interactivos.

## Características principales

- **Diseño responsivo y optimizado:** Adaptado a escritorio y dispositivos móviles de distintas gamas, evitando filtros pesados de GPU en pantallas chicas.
- **Identidad visual Midnight Glow:** Paleta en negro carbón, pizarra y bordó con televisor retro interactivo de 4 canales (`FrameTv1.jpg` – `FrameTv4.jpg`) con rotación automática y cambio manual al hacer clic.
- **Navegación fluida:** Desplazamiento suave desde el encabezado hacia cada sección y transiciones optimizadas.
- **Catálogo dinámico:** Carga de proyectos desde `data/demos.json` mediante `js/app.js`, con soporte para vistas previas en imagen y etiquetas de tecnologías.
- **Perfil profesional:** Secciones de stack técnico, experiencia laboral y formación académica.
- **Vista previa social:** Etiquetas Open Graph y Twitter Cards configuradas para compartir el enlace en WhatsApp y redes sociales.

## Estructura del proyecto

```text
MyPage/
├── css/
│   └── styles.css      # Estilos, paleta Midnight Glow y diseño responsivo
├── data/
│   └── demos.json      # Catálogo dinámico de proyectos accesibles
├── img/                # Frames de la TV (FrameTv1..4), capturas y og-preview.jpg
├── js/
│   └── app.js          # Scroll suave, cambio de canales en TV y carga de demos
├── index.html          # Estructura principal y metadatos Open Graph
└── README.md           # Documentación del repositorio
```
